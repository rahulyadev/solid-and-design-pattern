## Relationship types

- **Hard:** a correct Python mechanism is needed for the design unit.
- **Soft:** useful depth, but a short bridge is usually enough.
- **Optional deep dive:** valuable for advanced explanation, not required for first understanding.

When a unit is initialized, Codex should inspect the relevant rows above, mention only important Python prerequisites, and provide the minimum bridge when Rahul proceeds without them. Cross-repository links are supporting references; they do not block study and do not create progress entries here.

## Anchor rule

Python Mastery anchors are the lowercase form of the complete canonical ID, for example `PY-OBJ-010` → `#py-obj-010`. Never invent shortened IDs or guessed topic names.
