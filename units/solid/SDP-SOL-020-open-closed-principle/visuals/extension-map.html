How to read this visual

Choose a requirement and read each row left to right. Boxes name roles affected by the change. Their labels distinguish stable code, edits, and limits.

Key insight

A stable workflow can use new behavior. Wiring still changes, and a new shared promise can require edits on both sides.

Simplification or limitation

This is a hand-authored conceptual map, not a diff analyzer or cost measurement. Roles may share files. A stable box can still produce changed output.

No network requests, telemetry, or external libraries. The labels-only design supports its stated schema; other data languages could express more, at an additional cost.
