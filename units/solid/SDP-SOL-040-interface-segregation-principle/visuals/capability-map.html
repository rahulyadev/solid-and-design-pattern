How to read this visual

Read left to right, or top to bottom on a small screen. Arrows mean “depends on.” Start with Preview and Published bundle. Switch from Shared manager to Client capability.

Key insight

A client can require fewer operations while receiving the same object. Duplicate needs read and write together; a reading-only provider still cannot serve it.

Simplification or limitation

This is a conceptual typing model, not executed Python or a security boundary. It assumes the example's compatible signatures and models only read, write, and remove. It does not prove error behaviour, shared state, atomicity, permissions, or lifetime. Extra provider methods may exist; the annotation does not remove them.
