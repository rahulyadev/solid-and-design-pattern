Key insight

Simplification and limits

These are recorded observations from a synchronous Python probe with synthetic names and an in-memory sink. This page does not run Python or contact a service. Event positions do not measure duration. A matching trace covers the selected case, not every possible input or a real storage guarantee.

The full trace is part of the chosen observation boundary here. Some applications deliberately allow different read timing; establish that contract before accepting such a change.
