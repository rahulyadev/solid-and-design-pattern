# Visual — Builder construction-pressure explorer

Open [`construction-pressure-explorer.html`](construction-pressure-explorer.html) in a browser when
local-file policy permits it.

## How to read it

Choose one scenario tab, then read the five cards left to right on a wide screen or top to bottom
on a narrow screen:

1. identify the actual change pressure;
2. see when inputs become available;
3. locate the construction sequence;
4. locate final validation and lifetime ownership; and
5. accept or reject Builder as the smallest design.

The arrow keys, Home, and End move among scenario tabs. The content remains usable with reduced
motion and at the responsive single-column breakpoint.

## Key insight

The deciding fact is not the number of constructor arguments or whether methods return `self`.
Builder earns its cost when an incomplete construction process needs a private owner and one
explicit transition produces a valid Product.

## Simplification or limitation

This is a conceptual decision visual, not a Python object graph, type-state proof, thread schedule,
or CPython memory layout. It does not execute the worked example. The eight embedded scenarios are
mirrored by maintained Python data and contract tests; interactive rendering is separately recorded
in the validation evidence when browser policy allows it.
