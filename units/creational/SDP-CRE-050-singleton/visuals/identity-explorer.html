How to read this visual

Arrows mean returned references, not ownership or memory addresses. A single right-hand box means both displayed calls return the same object. In the retry case, only successful calls are drawn; the failed attempt is included in the count. In the two-app case, each left-hand box is an app owner.

Key insight

Identity, initialization count, safe publication, and lifetime are different promises. One object can be reinitialized; one coherent cache can let two factories run.

Simplification or limitation

These are conceptual relationships for five synthetic Python observations. The diagram is not a live thread scheduler, benchmark, memory layout, or proof of safety across all schedules. A creation lock does not guard later use. Each application shares internally; the two-app view compares roots.
