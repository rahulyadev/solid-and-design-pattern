How to read this visual

Key insight

Sharing within a request can be intentional. Isolation between requests is a separate promise.

Simplification or limitation

This is a conceptual graph of the synthetic Python experiment, not memory layout or a live Python interpreter. Root-to-child list containers are collapsed into edges. Split copying creates additional subgraphs; R₀′ and R₁′ denote those hidden roots, neither of which is the returned R′. Custom hooks, resources, and concurrent mutation are outside this visual.
