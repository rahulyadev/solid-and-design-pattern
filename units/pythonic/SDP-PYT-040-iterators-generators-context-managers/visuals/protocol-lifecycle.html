Key insight

Iteration controls when the next value is requested; a context manager controls what surrounds a block.

Simplification or limitation

This is conceptual synchronous flow, not stack frames, memory layout, async scheduling, or a resource transaction.

Iterable and iterator

The consumer pulls one value

A generator object is a one-pass iterator. Calling the generator function creates it; advancing it starts or resumes its body.

Context manager

The block has an exit policy

Successful entry guarantees an exit call. The exit method receives exception state and decides whether an exception propagates.

Context expression

Do not merge the two jobs

Laziness does not guarantee cleanup. If a stream owns a resource, keep consumption inside an explicit context or close it deterministically. Likewise, with does not make iteration reusable, bounded, thread-safe, retryable, or transactional.
