Reading guide and limits

How to read this visual

Choose a scenario. In mutation and rebinding, select Create, Mutate, then Rebind. Read each route from the callable's retained reference to the object it reaches, then compare the observed return value. Each step is a view of a fixed experiment; clicking out of order does not execute a new mutation.

Key insight

Changing an object and changing a name's binding are different operations. A default argument and partial keep the original list reference. The live closure follows the enclosing binding. The integer tuple snapshot is a separate value.

Simplification or limitation

List A and List B are conceptual labels, not addresses. The probe converts each returned tuple to a JSON array for storage; the first view displays it as a Python tuple. The snapshot contains integers only. Nested mutable values would remain shared after a shallow tuple conversion. The loop view concerns readers called after construction. No concurrency, serialization, or performance is modeled.
