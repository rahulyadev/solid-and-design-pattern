The ladder is not a maturity model

A function is not an immature metaclass. It is the correct tool when the operation can remain explicit. A descriptor is correct only when the repeated concern is attribute access. A subclass hook is correct only when an existing hierarchy owns a rule.

Metaclass question: what must happen before the class body, during class-object creation, or for every instance construction that no smaller boundary can express?

If the answer is unclear, stop. Build an explicit prototype and collect evidence before moving the behavior into class creation.
