How to read this visual

Move left to right through each row, then select the next stage. The centered label names the boundary operation; it is not an automatic dataclass conversion.

Key insight

A dataclass removes field boilerplate. The design comes from construction validation, finite enum states, immutable reachable fields, and explicit replacement.

Simplification or limitation

This is conceptual, not CPython memory layout or transaction control. It omits storage races, schema evolution, allocation cost, and garbage collection.
