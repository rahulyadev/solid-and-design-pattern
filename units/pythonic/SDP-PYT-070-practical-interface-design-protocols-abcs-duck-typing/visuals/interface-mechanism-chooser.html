How to read this visual

Choose a pressure, then read left to right. Runtime execution, static compatibility, and behavioral evidence answer different questions; the last card names the smallest likely fit, not a mandatory pattern.

Key insight

A callable, Protocol, or ABC can describe a call shape. Only behavior tests and operational evidence support claims about results, failures, effects, and history.

Simplification or limitation

This is a conceptual decision aid, not Python's object layout or a complete decision algorithm. Real boundaries may combine an adapter, static Protocol, and owned ABC.
